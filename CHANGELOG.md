## 3.2.0

* First public release of the Flutter bridge for the Permate Attribution SDK.
* Dart API, Pigeon-generated bridge, and thin Android/iOS plugin code only; the
  native SDKs are resolved as pinned binary dependencies.
* Requires Flutter 3.44 or later. iOS integration uses Swift Package Manager
  only; CocoaPods is not supported.
