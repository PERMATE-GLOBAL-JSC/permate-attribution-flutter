# Permate Attribution for Flutter

Pre-release. This repository is the public, rendered distribution of the
`permate_attribution` Flutter plugin. The package is not yet published on
[pub.dev](https://pub.dev/packages/permate_attribution); the first release
arrives through a reviewed pull request.

- Rendered output only: pull requests and issues here are not the place for
  changes to the plugin. Source changes are made upstream and re-rendered.
- Production releases are published to pub.dev from tags named
  `permate_attribution-v<version>` on `main`, through GitHub OIDC and the
  `pub.dev` environment. This repository holds no publishing credentials.
- Report vulnerabilities privately: see [SECURITY.md](SECURITY.md).

Requirements, installation, and usage are documented in the package README once
the first release lands.
